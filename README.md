KHUMTAI JAN SEVA — original deployment-ready starter

Run:
1. Install Node.js 18+
2. In this folder run: npm install
3. Change the initial admin password in data.json before deployment.
4. Run: npm start
5. Open http://localhost:3000

This is a production starter, not yet internet-hosted. Before public launch add HTTPS, hashed passwords, session/JWT auth, role-based permissions, secure photo storage, rate limiting, CSRF protection, audit logs, database backups, privacy policy and verified admin accounts.
